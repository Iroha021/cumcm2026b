## 三条铁律

1. `sim_client.py` 是唯一发 HTTP 的地方；
2. 实时路径（`run → runner → policy → world/geom → sim_client`）只允许标准库 + numpy，
   `matplotlib/scipy` 仅限 `paper/`、`tests/`；
3. `shadow.py` 只能被 runner 在 dryrun 模式下引用，不得进入 live 路径。

## 关键设计

- **串行单飞**：协议禁止并发不同动作，故全程单线程同步；策略与执行分离，便于回放与调参。
- **计时镜像**：`cost.py` 逐条复刻附件 1 表 2 的计时规则，并**逐次核对**预测耗时与实测虚拟
  时间增量（`cost_model_mismatches` 必须为 0）。
- **幂等重试**：网络异常时复用原 `request_id` 与原请求体重试，模拟器返回首次响应，
  不会重复移动/检测/计费。
- **信念更新**：观测似然在本题是指示函数（±1°、1000~1500 m、定向半平面），故用"按约束
  筛选粒子"统一实现；"某频道是否有源"用解析网格检验，避免蒙卡在 1e-3 量级似然上的退化。
- **无源检验**：`d_min` 网格化后解析求和；对定向源，无信号可能只是盲区，故证据按
  (1/2)^m 折算——这也意味着**定向源在原理上无法被证明不存在**，因此设置了每频道探测上限。
